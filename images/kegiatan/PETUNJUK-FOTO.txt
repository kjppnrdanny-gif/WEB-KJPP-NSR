PETUNJUK STRUKTUR FOLDER FOTO KEGIATAN KJPP NSR
=================================================

Untuk memudahkan Anda memilah dan merapikan foto kegiatan, folder ini sudah dipisah menjadi 4 kategori:

1. 📁 images/kegiatan/inspeksi/
   Khusus untuk foto kegiatan di lapangan:
   - Survei fisik tanah jalan tol / PSN
   - Inspeksi pabrik, kawasan industri, gudang
   - Sensus perkebunan kelapa sawit / karet
   - File default yang terhubung:
     * inspeksi-tol-psn.jpg
     * inspeksi-gedung-pabrik.jpg
     * inspeksi-kebun-sawit.jpg

2. 📁 images/kegiatan/raker/
   Khusus untuk foto rapat kerja & koordinasi internal:
   - Rapat kerja pimpinan kantor pusat & cabang (Bandung, Padang, Makassar, Palembang)
   - Evaluasi operasional kantor
   - File default yang terhubung:
     * raker-nasional-cabang.jpg

3. 📁 images/kegiatan/diklat/
   Khusus untuk foto pengembangan profesi:
   - Pelatihan Pendidikan Berkelanjutan (PPL) MAPPI
   - Seminar, sertifikasi penilai publik, workshop
   - File default yang terhubung:
     * pelatihan-diklat-mappi.jpg

4. 📁 images/kegiatan/kemitraan/
   Khusus untuk foto kegiatan bersama instansi:
   - Rapat koordinasi dengan ATR / BPN
   - Kunjungan / pertemuan dengan Bank mitra atau BUMN
   - File default yang terhubung:
     * koordinasi-instansi-bpn.jpg

CARA PAKAI SANGAT MUDAH:
- Anda cukup copy-paste foto ke dalam folder yang sesuai di atas.
- Anda bisa memberi nama foto bebas (misal: foto1.jpg, survei-tol.jpg, dll).
- Kapan saja Anda ingin mengganti nama kartu / menambah foto baru di website, cukup beri tahu asisten AI nama file fotonya!
