Dokumentasi Props & Parameter Lengkap

Parameter resmi dari React Bits <CountUp /> dengan varian JavaScript + CSS.

Prop Tipe Default Deskripsi
to number — Nilai angka tujuan akhir yang ingin dihitung (count up target).
from number 0 Nilai angka awal mulainya perhitungan.
direction string "up" Arah perhitungan: "up" atau "down". Saat "down", nilai from & to dibalik.
delay number 0 Jeda waktu tunda (dalam detik) sebelum animasi hitungan dimulai.
duration number 2 Durasi hitungan animasi (detik) berbasis parameter spring damping & stiffness.
separator string "" Karakter pemisah ribuan (contoh: "," atau ".").
startWhen boolean true Kondisi boolean untuk memicu hitungan saat elemen masuk viewport (useInView).
className string "" Kelas CSS kustom untuk styling tambahan font, warna, atau layout.
onStart function — Fungsi callback yang dipanggil saat animasi hitungan dimulai.
onEnd function — Fungsi callback yang dipanggil saat animasi hitungan selesai mencapai target.
